# Data Source Discovery Report

Research phase only. Nothing from this report has been imported into Pacio. Date:
2026-10-23. Four independent research agents were used (public repositories, official
sources, DSA/interview, jobs), plus a local provenance investigation; the lead agent
verified the key claims against the actual files and terms.

Register: `DATA_SOURCE_REGISTER.csv` (48 sources, each with URL, access date, licence,
verdict and limitations). DSA detail: `DSA_COVERAGE_AND_VALIDATION.md`.

Only **three** sources are cleanly approved today: `tech-interview-handbook` (MIT, study

code). None of them supplies institution or placement data.

## Workstream 0 — Provenance of the original data (VERIFIED, local)

- **No CSV/JSON/XLSX data file was ever committed.** Git history added only
  `backend/seed_data.py` and normal app files.
- `seed_data.py` contains no source URL for the “REAL KMIT PLACEMENT DATA”; the comment
  asserts authenticity but the tuples are hand-typed and cannot be traced to a published
  report. KMIT’s site publishes aggregates only.
- The only local artefacts are PDFs **generated by the app itself**
  (`CareerOS_placement_*.pdf`), not raw source data.
- Conclusion: **the original dataset’s provenance is unrecoverable.** The data is
  reconstructed/synthetic and must stay labelled as such. The classmate’s database is not
  accessible and no export exists.

## Workstream 1 — Public repositories and datasets

**Best institution source:** `Ash310u/All-India-Institutions-Data` — **39,268 AICTE
institutions**, JSON per state plus a 24 MB programme file, refreshed Oct 2025,
**Apache-2.0**, fields `aicte_id, institute_name, address, district, institution_type,
women, minority`. Limitation: it is a mirror of AICTE; AICTE’s own terms were not verified,
and it has no NAAC/affiliation data.

**Most tempting, worst rights:** `anxkhn/placement-data-2025` — 779 placements + 293
internships with company/role/CTC (LPA) and stipend. It has **no college, year or selects**,
carries a **GPL-3.0** licence on third-party-compiled data, and the author explicitly does
not validate entries. Use as a benchmark only; ask the author for a permissive licence.

**Best blueprint, no data:** `avantifellows/external_data_sources` — pipelines for AISHE
(53,559 colleges), AICTE (4,664), NIRF DCS placements (29,505) and NIRF rankings (10,707),
with schemas but **no licence and no shipped data**.

**Rejected:** NIT-KKR 2021 (no licence), the Kaggle “India colleges” CC0 set (values
implausible — identical averages across different IITs), scraped Internshala listings
(uploader cannot relicense), synthetic student sets, and `colleges-api` (uninspectable).

**Not found anywhere:** an openly licensed, **multi-institution**, company-level Indian
placement dataset. One institution (KMIT) does publish per-company selects/CTC for
2017-18→2023-24; the seed's 2024-26 rows and all average-package figures are modelled, not
published. The exact multi-college structure used by the hackathon seed does not exist
publicly.

This changes one earlier conclusion: **KMIT does publish company-level placement data**,
through 2023-24, so the seed's pre-2024 tuples can be replaced with a cited public source.
It still publishes no average/median, so those figures must be labelled as modelled or
removed. No other institution examined publishes comparable per-company tables.

## Workstream 3 — DSA and interview intelligence

The current 108-problem catalogue is original in wording but **not executable**: 0/108 have
examples, constraints, signatures or tests. Every major source of problem text (CSES,
Project Euler, LeetCode, GfG, HackerRank, Codeforces) is **blocked** for commercial reuse;
the Kaggle “LeetCode CC0” mirror is licence laundering. Permitted: MIT code repositories for
reference solutions, CC BY 4.0 system-design material, and DeepMind CodeContests for
calibration only. Full analysis and schema: `DSA_COVERAGE_AND_VALIDATION.md`.

## Workstream 4 — Jobs and internships

| Source | India | Verdict |
| --- | --- | --- |
| Adzuna | **Yes, 500k+ ads claimed** | **BLOCKED commercially** — paid licence required; 14-day trial only |
| Jooble (existing) | Key is country-specific | **PARTIAL** — 500 requests per key lifetime; docs 403 to bots; display-only, terms unclear |
| Greenhouse / Lever / Ashby public boards | **Yes** — verified live: CRED (8 jobs, Bengaluru/Mumbai/Hyderabad), Atlan (6 jobs, 4 India) | **APPROVED_WITH_LIMITATIONS** — metadata + canonical apply URL; ToS silent on third-party aggregation |
| RemoteOK / Remotive | Remote only | Approved with attribution/rate limits (Remotive: 4 requests/day, no redistribution) |
| Arbeitnow | **No** (Germany/UK/FR/CH/NL) | Not suitable |
| Naukri / LinkedIn / Indeed / Internshala mirrors | — | **REJECT** — terms prohibit scraping/redistribution |

Recommended ingestion: per-employer ATS boards (authoritative, smallest legal risk), with
dedupe key `sha256(source|board|external_id)`, a soft-close after two missed polls, and an
honest empty state. Adzuna is the one feed worth buying for India coverage.

## Workstream 5 — Institutions, placements and partnerships

- Institution facts can be sourced (AICTE mirror now; AISHE after permission).
- Placement statistics exist only as **published aggregates** per institution
  (offers, placed counts, median/average/highest salary), not company-level selections.
- **No public source supports MOUs, payouts or partnerships.** Those records must remain
  synthetic and explicitly labelled; an institution’s appearance in any dataset is not
  evidence of a relationship with Pacio.

## Workstream 6 — Licensing summary

- Clean for commercial use: MIT (tech-interview-handbook, TheAlgorithms), CC BY 4.0
  (system-design-primer).
- Attribution/limits: RemoteOK, Remotive, ATS boards (silent, not granting), Apache-2.0
  mirror (upstream unverified).
- Blocked: NIRF, AISHE, AICTE, data.gov.in (unverified), Adzuna (commercial), Jooble
  (unclear).
- Rejected: LeetCode, GfG, HackerRank, Codeforces, CSES, Project Euler (NC), scraped
  Internshala, CC0 LeetCode mirrors, CC BY-SA material for a closed product.

## What remains unknown

1. Whether AISHE/AICTE will grant written permission to redistribute their directory rows
   (their published terms currently say no).
2. Whether the OGD "sandbox" AISHE tables are accurate enough to use (the portal warns they
   may be incomplete).
3. Adzuna’s exact India commercial pricing.
4. Whether any employer ATS terms affirmatively allow third-party aggregation (silence is
   not permission).
5. The provenance of the classmate’s original dataset — no trace exists locally.
6. Whether any Indian institution publishes company-level placement data (none found).

## Recommendation

1. **Institutions:** AISHE counts and AICTE rows are readable but require written consent for
   redistribution; OGD/GODL is the cleanest licensed route once a key is obtained. Keep any
   imported directory in `institutions_public`, never overwriting the synthetic tenant.
2. **Placements:** replace KMIT’s **2017-18→2023-24** tuples from its published table with
   URL/year citations; mark 2024-26 and every average/median figure as modelled or remove
   them. For other colleges, use only institution-published aggregates with year and
   definition, or build first-party data. There is no multi-college company-level dataset to
   buy or copy.
3. **Jobs:** ingest ATS boards for named Indian employers; licence Adzuna if India coverage
   matters; keep Jooble only as a legacy bridge and rotate its key.
4. **DSA:** validate the 108 problems with tests before expanding; use MIT code for oracle
   solutions; never copy blocked problem text.
5. **Label everything:** synthetic vs published vs verified, in the data and in the UI.

The dataset is now a documented starting point, not a solved problem. The highest-value
legitimate work is first-party college data and licensed job feeds, not bulk scraping.
